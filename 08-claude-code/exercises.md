# Module 08 — Exercises

See [`lab.md`](./lab.md) for the full hands-on checklist. Below are reflection prompts to internalize what you learned.

## 1. Goal vs steps
Find a recent prompt of yours that listed steps instead of goals. Rewrite it as a goal. Run both versions. Which produced better edits with fewer revisions?

## 2. Permissions vs friction
Identify the 5 commands that prompt for permission most often in your daily work. Add them to `.claude/settings.json` allowlist. Note the time saved over a day.

## 3. Slash command audit
List the 3 prompts you retype most often this week. Convert each to a slash command under `.claude/commands/`. Measure usage.

## 4. Custom agent boundaries
You have agents for `Explore`, `Plan`, `general-purpose`. For your domain, what's a 4th specialized agent worth defining? Describe its trigger conditions and tool whitelist.

## 5. Hook ROI
Of all the hook events, which 2 would most improve your workflow? Implement them. After a week, measure: do they fire too often / too rarely?

## 6. MCP fit test
List 3 internal tools at your work (or in OSS). For each, decide: MCP server, ad-hoc CLI, or skill? Justify.

## 7. Read CLAUDE.md
Open a real OSS project's `CLAUDE.md` (search GitHub: `path:CLAUDE.md`). What conventions are they encoding? What would you steal?
